## 수치·문구의 해석

월간 헤드라인·전월 값·변화량·구간은 같은 비교 가능 표본에 연결한다. 서비스별 카드는
기존 질문별 평균 추정량을 유지하며, 실제 확정 답변 수와 언급 답변 수를 같이 표시한다.
전체 답변 합산과 서비스별 질문 평균의 가중 방식은 다르므로 단순 평균으로 역산하지 않는다.
인용은 답변 반복 수가 아닌 '질문·AI 서비스 조합' 단위로 표시한다.

미측정, 0회 언급, 일부 측정은 다른 상태다. 반복 횟수가 줄거나 한 서비스가 빠졌다고
실패를 미언급 0으로 채우지 않는다. 실제 질문·모델·프로토콜이 달라지면 전월 증감을 만들지 않는다.
계획된 반복이 아직 생성되지 않은 경우에도 계획 분모는 유지하되, 그 결과를 성공으로 만들지 않는다.
같은 관측의 중복 사용이나 잘못된 소유권은 명시적인 데이터 오류로 중단한다.

약정 이행은 원 계약 월에 귀속하고, 대상 기간의 실제 공개·선행 발행·지연 보충은 구분한다.
다른 달 이월분으로 이번 달 편수를 채웠다고 말하지 않는다. 부족이 있으면 다음 운영 계획에
안전 기준을 통과한 글부터 보충한다는 순서를 포함한다. 리포트 생성이 미달 글의 발행을 허가하지 않는다.

## 출력 품질과 검증

A4 요약 1쪽에 약정 이행·서비스별 관측값·전월 비교·답변 발췌·다음 운영 계획을 배치한다.
요약 제목 18pt, 본문 10pt, 보조 글자 8pt 이상인 명시적 두 밀도만 사용한다. 끝없이 글자를
줄여 끼워 넣지 않는다. 전체 질문표는 표 머리글을 반복하고 긴 문장을 줄바꿈하며 행을 나누지 않는다.
페이지 번호는 전체 쪽수와 함께 표시한다. 병원명·기간·요약 수치·필수 주의 문구를 첫 쪽에서 확인한다.

PDF bytes를 만든 뒤 A4 규격, Pretendard 포함과 한글 매핑, 공개 링크, 질문표의 모든 행/항목과
순서를 검사한다. 페이지 anchor로 요약 끝과 행 끝이 용지 안에 있는지도 확인한다.
원본 HTML에 문자열이 있다는 것만으로 통과시키지 않는다. 확인한 실제 bytes의 SHA-256/크기를
업로드·artifact metadata와 결합한다. 기존 v1의 1~2쪽 계약은 그대로 읽고 새 v2는 검증된 페이지 수를 읽는다.

## 적용 범위와 남는 한계

이번 작업은 코드와 격리된 검증 자료에만 적용했다. 운영 DB, 기존 고객 보고서, 전달 이력,
실제 측정 공급자, Slack 발송은 변경하지 않았다. 따라서 이미 전달된 보고서가 이 결함으로
잘못됐다고 단정하거나 자동 재발송하지 않는다. 기존 보고서는 기존 bytes/hash를 유지한다.
새 생성·명시적 재생성부터 v2 렌더러가 적용되며 운영 반영에는 Backend 배포가 필요하다.

본문은 요약이므로 일부 예시를 줄일 수 있다. 필수 측정 범위·의료 주의 문구와 질문표 전체는
없애지 않는다. 예시 인용은 발췌라는 표시와 말줄임을 사용하며 취소선·주의·X 표시의 의미를
텍스트로 보존한다. 문서 입력은 최대 512행, 항목당 2,000자, 32쪽으로 제한한다. 한도를 넘으면
일부를 몰래 버리는 대신 검증 오류로 중단하고 기존 artifact 복구 경로에 맡긴다.

고정 lineage가 없는 과거 기록의 반복 횟수·질문 의도를 추측하여 복원하지 않는다.
LEGACY_UNKNOWN은 그대로 구분한다. 반복 질문이 독립 표본이라는 가정은 검증된 사실이 아니며,
95% 참고구간이나 숫자 변화가 실제 ChatGPT/Gemini 이용자 화면, 검색 순위, 방문 환자 증가,
콘텐츠 발행의 인과 효과를 보장하지 않는다. 보고서는 관측·계약 이행·다음 운영을 설명한다.

검증용 PDF는 가상 데이터를 사용한다. `checked-monthly-example.pdf`의 숫자는 고객 실적이 아니다.
로컬 PDF 이미지와 전체 질문 순서를 점검하며, 데이터 적음·부분 측정·비교 불가·긴 질문과
70개 질문의 자동 페이지 나눔까지 검사한다. 원본 이미지와 로그는 별도 임시 검증 폴더에 보존한다.
