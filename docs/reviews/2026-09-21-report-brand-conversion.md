# 리포트 브랜드·도입 설득 구조 개편

기준: main `4fe1e4c` 이후 보고서 전용 변경. 운영 배포·고객 발송·기존 보고서 일괄 갱신 없음.
공개 랜딩의 실제 블루·블랙·화이트 브랜드와 서비스 운영 범위를 참조했다.

## 진단 제안서

첫 장은 ‘우리 병원의 강점이, AI가 답할 근거가 되도록’이라는 목적과 실제 진단 수치를
함께 보여준다. 두 번째 장은 왜 지금 준비할지와 해당 질문에 맞춘 실행안을 연결한다.
세 번째 장은 공개 정보 허브·질문별 콘텐츠·월간 해석이라는 산출물, 전담 마케터의
운영·설명, 기존 가격·편수, 지역 중복 검토 후 상담 행동을 보여준다.

시간을 들여 정보와 공개 기록을 쌓는 이유를 설명하되 선점 순위·환자 증가·효과 발생
기한을 보장하지 않는다. 지역 중복 검토는 보장된 독점권이나 잔여 자리 수가 아니다.
병원 도메인 사용은 온보딩에서 협의하며 해지 이후 영구 호스팅을 약속하지 않는다.
출처가 확인되지 않은 시장 비율·사례 성과·경쟁사 가격은 추가하지 않았다.

## 월간 보고서

동일 조건의 전후 비교를 크게 배치하고 수행 기록과 관측 결과를 나눈다. 실제 작업과
소유 URL 인용을 비대칭 포트폴리오로 연결하며, 긍정·미언급 근거는 모두 보존한다.
약정 이행과 다음 달 실행을 분리하고 전담 마케터의 후속 설명을 명시한다.
인용 미확인·관측한 인용 0·출처 확인을 다른 상태로 표시한다. 작업이 없는 경우
발행을 완료했다고 쓰지 않는다. 측정 집계·비교 적합성·전달 권한은 변경하지 않았다.

## 지면과 검증

블루 결과 패널, 블랙 핵심 문장, 비대칭 작업/증거 구성, 공개 자산 지도와 실행 원장을
사용한다. 동일 눈금의 비교 막대는 실제 렌더 너비와 배경 대비로 검증한다. 좁은 근거
표의 한글 줄바꿈 기회를 보존하며 본문 3쪽과 전체 부록의 텍스트·링크 검증을 유지한다.

전체 Backend 회귀 4,567개 통과 후 마지막 문구·결측 상태를 보완했고, 최종 보고서·
배포 스크립트 범위 205개와 랜딩 카피 35개를 다시 검증했다. 앞뒤 테스트는 중복되어
합산하지 않는다. Ruff, 사용자 문구 및 DB 연결 예산 검사도 통과했다.
9종 가상 PDF 44쪽을 실제 렌더러로 생성했으며 본문·부록 필수 내용과 페이지 경계를
검증했다. Poppler의 독립적인 텍스트 좌표 검사에서도 페이지 밖 글자는 없었다.
대표 지면과 결측·내부용 상태는 PNG로 직접 확인했다.

## 재현과 반영 경계

`scripts/report_design_samples.py --png`로 같은 가상 문서를 생성한다. 보고서 브랜치
push에만 동작하는 별도 preview CI는 운영 자격 증명 없이 PDF·PNG·manifest만 보관한다.
원본 폰트·로컬 경로가 들어간 HTML·고객 자료는 업로드 대상이 아니다.
리드 템플릿 버전은 `lead-v11`이며 기존 원장용 PDF의 v1/v2/v3 호환성은 유지한다.
INTERNAL은 모든 쪽에서 AE 전용으로 표시하며 고객용 링크나 발송 권한을 추가하지 않는다.
랜딩의 ‘2장’이라는 오래된 설명만 실제 제공 내용 중심으로 수정했다.
코드 커밋·브랜치 push까지만 수행하며 main 병합이나 운영 배포는 하지 않는다.
