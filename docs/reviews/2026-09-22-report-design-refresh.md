# 리포트 디자인 개편 — 진단 제안서·월간 보고서·내부 운영 리포트

기준: main `267b100` 이후 보고서 템플릿·스타일 전용 변경. 운영 배포·고객 발송·기존 보고서 일괄 갱신 없음.
요소·문구·수치·검증 계약은 그대로 두고 지면 디자인만 바꿨다. 참조한 방향은 현행 편집형 데이터 리포트의
공통 문법이다 — 흰 바탕 위 큰 표형 숫자, 헤어라인으로 나눈 모듈, 한 장에 하나의 어두운 선언 면,
역할 라벨과 쪽 번호를 둔 러닝 헤드, 전폭 헤어라인 위의 출처 라인.

## 무엇이 바뀌었나

공유 스타일 `report_editorial.css`를 다시 썼다. Pretendard 가변 폰트를 100~900 범위로 선언해
ExtraBold(800)·Bold(700)·Medium(500)·Light(300)을 실제로 쓴다. 상단 3pt 파란 바는 잉크 헤어라인
마스트헤드로 바꾸고, 우측 상단 러닝 헤드에 검증용·INTERNAL 라벨과 `쪽 / 전체`를 둔다. 하단은
`@bottom-left`를 전폭으로 잡아 헤어라인과 출처 라인을 같은 높이로 반복한다.

KPI 스트립은 파란 배경 패널에서 흰 바탕으로 옮겼다. 지표마다 1.5pt 잉크 룰을 위에 긋고 격자와
세로선을 두지 않는다. 숫자는 44pt ExtraBold 잉크이며, 진단서의 언급 비율과 월간의 전월·이번 달은
같은 4pt 트랙 위의 막대로 표시한다 — 전월은 검정, 이번 달은 파랑, 변화폭은 이번 달 칸 아래 한 줄이다.
표는 헤더 색 밴드·zebra·세로 구분선을 없애고 작은 회색 라벨과 잉크 룰 하나로 처리했다.
박스 좌측 accent bar(병원명 레일, 마케터 패널, 작업 관측 열, 사례 패널)는 전부 제거했다.
어두운 선언 면(왜 지금·약정 이행·근거 없음 대체)과 연한 파랑 강조 패널(마케터 후속, 언급 근거)은
한 장에 두 개 이하로 유지한다. 진단서의 실행안은 라벨 열과 값 열을 헤어라인으로 나눈 스펙 시트로,
첫 달 프로세스는 라벨 열을 고정한 원장(ledger) 형태로 바꿨다.

내부 AE 리포트 `report.html`은 같은 스타일시트를 include 하고 KPI·주의·액션 박스만 덮어쓴다.
남색 커버 카드, 둥근 모서리, 노란 강조 박스, 표 헤더 색 밴드와 zebra가 사라졌다. 문구와 데이터 바인딩은
그대로다. 레거시 `doctor_report.html`(doctor-pdf-v1/v2)은 손대지 않았다.

## 계약 유지

리드 템플릿 버전은 `lead-v11`에서 `lead-v12`로 올렸다. 본문 3쪽과 부록의 앵커·필수 문구·링크·폰트·
해시 검증은 그대로이며, 월간 본문 쪽 마커만 새 역할 라벨(`01 / 관측과 결론`, `02 / 수행과 증거`,
`03 / 다음 결정`)에 맞춰 `report_artifact_validation.py`에서 함께 바꿨다. 이 마커는 생성 시점
검증에만 쓰이므로 저장된 기존 아티팩트에는 영향이 없다. doctor-pdf-v3 버전과 쪽수 경계(4~32쪽)는
유지된다. 비교 막대의 동일 트랙 너비·비례 채움·배경 대비 검증은 새 색(트랙 rule, 채움 accent/ink)으로
그대로 통과한다.

## 지면과 검증

`scripts/report_design_samples.py`로 가상 9종을 실제 렌더러로 생성했다. 쪽수는 개편 전과 같다 —
월간 4종 5쪽, 고밀도 8쪽, 진단 4종 4쪽. 본문 3쪽 끝 앵커는 모두 각 쪽 안에 있고(진단 3쪽 끝 y=1012px,
쪽 높이 1123px), 어느 쪽에서도 요소가 지면 밖으로 나가지 않았다. 내부 AE 리포트는 월간·V0 가상 컨텍스트로
따로 렌더해 PNG로 확인했다. 대표 지면(진단 1~4쪽, 결측·INTERNAL, 월간 1~4쪽, 결측·고밀도)을 PNG로
직접 확인했다.

로컬에서 보고서 관련 회귀 12개 파일(`test_lead_report_*`, `test_report_*`, `test_monthly_sov_report`,
`test_lead_proposal`) 143개 통과·9개 skip(DB/Redis 의존)이며 `ruff check`도 통과했다. 내부 리포트가 공유 CSS를
포함하면서 `unknown` 클래스명이 원시 코드 누출 검사에 걸려 `withheld`로 바꿨고, 내부 리포트의 편집 규칙
(둥근 모서리·그림자·zebra·옛 남색 없음)을 고정하는 테스트를 추가했다.

## 재현과 반영 경계

`REPUTATION_DISABLE_DOTENV=1 APP_ENV=test uv run --project backend --frozen --no-sync python scripts/report_design_samples.py --png`으로
같은 가상 문서를 만든다. 이 브랜치 이름은 `feat/report-*` 패턴이 아니라 별도 preview CI는 돌지 않으며,
main CI의 샘플 렌더 단계가 같은 스크립트를 실행한다. 코드 커밋·브랜치 push까지만 수행하며 main 병합이나
운영 배포는 하지 않는다.

## 후속 보완 — 병합 뒤 전 지면 재검수

병합 뒤 가상 9종과 내부 AE 리포트를 다시 렌더해 전 쪽을 PNG로 보고, PDF의 도형 좌표로 레일 정렬을 측정했다.

- 레일 정렬: `border-spacing`으로 단 간격을 만든 모듈(`.metrics`·`.asset-grid`·`.readout`, 내부 `.kpi-grid`)이
  왼쪽만 음수 여백으로 당기고 폭은 100%로 두어, 오른쪽 끝이 간격 두 배만큼 짧았다. 진단 1·3쪽과 월간 1쪽,
  내부 1쪽의 KPI 스트립과 3단이 레일(547.1pt)보다 24~32pt 앞에서 끝났다. 폭에 간격 두 배를 더해 양쪽 레일에
  맞췄고, 같은 규칙을 `test_gutter_grids_reach_both_rails`로 고정했다.
- 수행/관측 2단: 오른쪽 `OBSERVED` 라벨이 왼쪽 라벨보다 4pt 아래에 있던 것을 같은 기준선으로 맞췄다.
- 약정 이행 면: 라벨과 36pt 숫자를 한 줄에 두던 배치를 KPI 스트립과 같은 라벨 위 숫자 순서로 바꿨다.
- 진단 2쪽 실행안: 스펙 시트 마지막 행에 닫는 헤어라인을 긋고, 뒤따르는 출처 문장과의 간격을 12pt로 벌렸다.
- 내부 리포트: 원장 미팅 토킹 포인트가 쪽 경계에서 제목·설명과 목록으로 갈라지지 않게 한 묶음으로 넘긴다.

측정 결과 9종·내부 리포트 전 쪽에서 레일 밖 요소 0건, 레일보다 짧게 끝나는 모듈 0건이며 쪽수는
월간 5쪽·고밀도 8쪽·진단 4쪽·내부 3쪽으로 그대로다. 문구·수치·검증 마커·`lead-v12`는 바꾸지 않았다
(#148이 아직 운영에 나가지 않아 같은 버전 안의 수정이다).

## 뉴비짓 소개서 요소 반영

Re:putation은 모션랩스의 병원 마케팅 브랜드 뉴비짓이 제공하는 서비스다. 그래서 진단 제안서·월간 보고서·내부 AE
리포트가 뉴비짓 서비스 소개서(v52)의 핵심 요소를 공유하도록 했다. 소개서를 그대로 입히지 않고, A4 인쇄 문서에서
의미가 있는 것만 가져왔다.

가져온 것은 다음과 같다. 색은 파랑·청회색을 걷고 흰색·검정·무채색 회색 위의 주황 하나로 줄였다. 크기가 있는 표시
(막대·룰·마스트헤드 표식·표지 대시·헤드라인 강조·검은 면의 수치)는 `#ff3d00`, 작은 글자와 CTA 면은 흰 바탕 대비
5:1인 `#d13200`을 쓴다. `#ff3d00` 단독은 3.6:1이라 9pt 라벨에 쓰지 않는다. 헤드라인은 한 구절만 주황으로 강조하고,
표지 약속 문구 위에 짧은 주황 대시를 둔다. 마스트헤드 오른쪽은 소개서의 eyebrow처럼 주황 번호와 잉크 라벨로 나누고,
잉크 헤어라인 왼쪽 끝에 소개서 상단 진행선을 닮은 주황 표식을 붙였다. 목록 번호는 큰 옅은 회색 숫자, 목록과 표는 2pt
검정 룰로 열고 닫는다. 선언 면과 약정 이행 면은 순수 검정이며 이행 수치는 주황이다. 월간 비교는 지난달 검정, 이번 달
주황 막대와 룰이다. 러닝 헤드와 하단 출처 라인은 자간을 벌린 대문자로 쓰고, 하단은 `NEWVISIT · RE:PUTATION`과
`MOTIONLABS INC.`로 나눴다. 마스트헤드 표기는 `Re:putation by Newvisit`, 진단서 3쪽 소제목은 `WHY NEWVISIT`이다.

가져오지 않은 것도 있다. 원·점·라운드 칩·카드, 화살표 흐름, 전면 색 페이지는 슬라이드의 장치라 인쇄 지면에서는
헤어라인 체계와 부딪힌다. 9pt 미만 글자 금지 규칙도 그대로 지켰다.

월간 본문의 막대 설명은 색이 바뀐 만큼 "이번 달은 주황 막대"로 고쳤다. 쪽 마커(`01 / 관측과 결론` 등)는 번호만
색을 입히는 span으로 감쌌을 뿐 추출 텍스트가 같아 생성 시점 검증을 그대로 통과한다. 가상 9종·내부 리포트의 쪽수와
레일 측정 결과는 앞 절과 같다. 색 체계와 브랜드 표기는 `test_reports_carry_the_newvisit_signal_system`으로 고정했다.
