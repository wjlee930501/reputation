# 2026-09-07 월간 계약 이행·원장 리포트 복구

## 서비스 기준

계약된 12·16·20편을 병원의 승인된 운영 기준과 의료 안전검사 아래 자율 발행한다.
매월 초 전월 리포트를 생성하고 AE가 원장에게 설명·전달한다. 시스템은 원장 전달이나
AE의 확인을 대신 완료 처리하지 않는다. AI 노출도는 측정 질문·플랫폼·시점이 확인되는
실제 관측치이며 진료 품질이나 환자 증가를 보장하는 수치가 아니다.

## 원인과 수정

- 캘린더가 선택한 요일의 날짜 수에 맞춰 약정 편수를 잘랐다. 날짜가 부족하면 추가
  날짜·동일 날짜 슬롯을 사용해 계약 총량을 보존한다. 매일 21:30 현재 월 누락 슬롯을
  대조·복원하며 병원 잠금과 기존 순번 검사로 중복 생성을 막는다.
- 이월 글은 원래 계약 월에 귀속한다. 실제 발행일은 변경하지 않는다. 오래된 미발행
  초안도 기존 안전검사를 통과한 뒤 복구할 수 있다.
- 보고 월 이후 변경한 요금제가 과거 리포트 분모를 바꾸지 않도록 당시 스케줄을 조회한다.
  기간 내 실제 발행과 기간 전 공개·마감 후 보충 발행을 구분한다.
- 원장용 PDF를 기본 다운로드로 제공한다. AE 자료는 명시적으로 분리한다. 한글 글꼴,
  PDF 표 레이아웃, 긴 문장, 답변의 Markdown·장식 문자를 정리했다.
- 질문의 플랫폼별 ID를 중복 질문으로 세던 집계와 부록 중복을 수정했다. 동일 질문을
  묶고 ChatGPT·Gemini의 실제 성공 응답 수와 질문별 평균 언급률을 표시한다.
- 생성 직전 질문 배정이 높은 우선순위의 질문만 반복했다. 유형이 맞는 질문 중 아직
  사용하지 않은 질문을 우선하고, 부분 캘린더 복구에서도 기존 질문 배정을 재사용하지
  않도록 했다. 재생성 피드백도 새 브리프에서 보존한다.
- 노원탑365의 감별진단 주의 문구를 자료 간 충돌로 오분류하여 최신 운영 기준 검수를
  막고 있었다. 원문을 대조하고 추출·합성 프롬프트와 엄격한 분류 보정을 수정했다.
  해당 자료 1개를 정상 재처리한 뒤 독립 AI 검수가 새 스냅샷을 승인했다.
  실제 상충 근거의 차단이나 사람의 승인 기록은 변경하지 않았다.

## 운영 복구 범위

행복드림의원·장편한외과의원·연세속시원내과의원의 8월 원계약 슬롯은 각각 8개였다.
각 4편씩 총 12편을 보충했다. 기존 승인 운영 기준·의료 안전검사·정상 공개 절차를
그대로 사용했다. 장편한의 8월 실제 공개 9편에는 이전 월 이월 1편이 포함됐으며,
행복드림·연세속시원의 실제 공개 7편과 원계약 공개 8편의 차이는 기간 전 공개 1편이다.
이 때문에 화면상의 9/12·7/12를 단순 차감하지 않고 원계약 귀속을 대조했다.

연세속시원내과의 새 보충 글 4편에서 주제 중복을 발견하여 그중 3편의 원문을 비공개
저장소에 백업하고 정상 반려·재생성 절차로 서로 다른 진료 질문에 답하도록 수정했다.

7개 병원의 9월 캘린더는 12·12·12·12·12·20·20편이다. 아직 미래인 9월 전체가
이미 발행됐다는 의미는 아니다. 안전검사가 실패하면 공개하지 않고 복구 대상으로 남긴다.

8월 보고용 AI 측정은 기존 저장된 9월 4~6일 복구 관측이다. 8월에 실제 측정한 것처럼
표시하지 않으며, 실제 관측 기간을 원장용 PDF에 명시한다. 각 병원은 고유 질문 15개,
ChatGPT(luna)·Gemini 2개 플랫폼, 질문당 반복 관측을 사용한다.
