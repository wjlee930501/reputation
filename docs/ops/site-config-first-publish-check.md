# 레이아웃 편집기 — 첫 공개 반영 점검 절차

작성 2026-11-21 · 대상: 공개 반영 막음을 걷은 배포(#373) 직후 처음 몇 병원 · 설계: [섹션 설정 설계](../plans/2026-11-20-clinic-site-sections-design.md) 22절

공개 반영은 공개 페이지를 몇 분 안에 바꾼다. 첫 반영은 **화면이 바뀌지 않는 반영 → 작은 변화 하나 → 되돌리기** 순서로, 한 병원씩 확인한다.

## 0. 시작 전 (배포 직후 한 번)

1. 점검 CLI를 실행한다(읽기 전용):
   `gcloud run jobs execute reputation-migrate --wait --args=python,-m,app.utils.site_config_precheck`
2. 마지막 줄 `summary`를 본다.
   - `published_diverged`는 0이어야 한다.
   - `drafts_rejected_now`가 0이 아니면, 그 병원은 편집기에서 '변경 있음'으로 잡힌다. 저장을 한 번 해서 정리한 뒤 반영한다(정리 전 반영은 422).
3. 편집기 '미리보기'가 열리는지 본다. '미리보기 준비 전'이면 `SITE_PREVIEW_TOKEN_SECRET`가 없는 것이므로 **반영하지 않는다**.

## 1. 첫 병원 고르기

- **첫째:** **장편한외과의원**(`jangpyeonhanoegwayiweon`, 레이아웃 B, 사진 19장). B는 레이아웃 도입 전 화면과 섹션·순서가 같고, 대표가 11-14에 직접 B를 골랐다.
- **둘째:** **365서귀포삼성정형외과**(B)
- **셋째:** **다대으뜸내과**(C) — A·C는 B를 확인한 뒤에 한다.
- **피할 병원:**
  - 레이아웃이 없는 병원(유내과·장보고 등 옛 화면). 편집기를 쓰려면 레이아웃을 먼저 골라야 하고, 고르는 순간 화면이 바뀐다.
  - 자기 도메인 병원. 캐시·도메인이 한 겹 더 있다.

## 2. 화면이 바뀌지 않는 반영 (병원마다 먼저)

1. **편집기를 연다.** 병원 → 병원 정보 → 레이아웃 편집. 아무것도 바꾸지 않은 채 '임시 저장' 버튼이 눌리지 않는지(바뀐 것 없음) 본다.
2. **기본값으로 초안을 만든다.** '기본으로 되돌리기' → 지금 레이아웃 → '기본값으로 임시 저장본 만들기'.
3. **미리보기와 공개 화면을 대조한다.** 미리보기를 공개 페이지 새 탭과 나란히 놓고 다음이 같은지 본다.
   - 섹션 순서·제목
   - 첫 화면 정보 띠
   - FAQ 질문 수
   - 의료진
   - 오시는 길
   - 휴대폰 폭(개발자 도구 375px)
4. **'공개 반영'을 누른다.** 몇 분 뒤 공개 페이지를 새로고침해 다음을 본다.
   - 화면이 그대로인지
   - 편집기 상태 줄이 '공개 중 설정 1판'인지
   - 공개 API `…/api/v1/public/hospitals/{slug}`의 `site_config.version`이 1인지
5. **구조화 정보가 그대로인지 본다.** 페이지 소스에서 다음을 확인한다.
   - JSON-LD(`MedicalClinic`·`FAQPage`)가 반영 전과 같은지
   - 화면 FAQ 질문과 `FAQPage` 질문이 같은지
   - `/{slug}/llms.txt`가 바뀌지 않았는지

## 3. 작은 변화 하나

1. **한 칸만 바꾼다.** 예: 자주 묻는 질문 섹션 제목, 또는 진료 영역 안내 문구. 의료광고 금지 표현은 저장이 막힌다.
2. **저장한 뒤 확인한다.**
   - 저장 → 미리보기에서 그 칸만 바뀌었는지 본다.
   - 반영 → 공개 화면에서 그 칸만 바뀌었는지 본다.
   - 섹션 제목을 바꿨다면 메뉴·바로가기 앵커(`#faq` 등)가 그대로 이동하는지 본다.
3. **오류 로그를 본다.** Site 리비전 ERROR가 반영 뒤 10분 동안 0건인지(Cloud Logging, `reputation-site`).

## 4. 되돌리기

- **바로 전 판으로:** 편집기 '공개 이력'에서 1판 → '이 판으로 임시 저장본 만들기' → 공개 반영. 버전이 하나 올라가고 화면은 1판으로 돌아간다.
- **처음 화면으로:** '기본으로 되돌리기' → 공개 반영. 직접 바꾼 칸이 모두 비워지고, 레이아웃 기본값 = 지금 화면이 된다.
- **공개 반영 자체를 다시 막기:**
  - #373을 되돌려 Admin을 배포하면 편집기의 '공개 반영' 버튼만 막힌다.
  - **이미 공개된 판은 그대로 남는다.** 화면을 되돌리려면 먼저 위 두 방법으로 반영한 뒤 막는다.
- **화면이 깨졌을 때:** 원인을 찾기 전에 '기본으로 되돌리기'로 반영한다(서버·사이트 배포 없이 몇 분 안에 돌아온다).

## 5. 기록

병원마다 다음을 배포 기록에 남긴다.
- 반영한 판 번호
- 바꾼 칸
- 대조한 화면(PC·휴대폰)
- 되돌리기 확인 여부
