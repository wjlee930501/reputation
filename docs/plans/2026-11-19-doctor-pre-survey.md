# 원장 사전 설문 — 원장이 링크에서 직접 작성 (2026-11-19)

상태: PR1(링크·작성·제출·근거 자료) 구현. PR2(사진·로고·인증서 올리기), PR3(사실 답변을 AE가 병원 정보에 반영)는 이어서.

## 왜

D32로 원장 인터뷰 설문(`SourceType.INTERVIEW`)은 Essence의 최우선 근거가 됐지만, 받는 길은 AE가 Word·Google 문서로 따로 받아
PDF·공유 링크로 다시 올리는 것 하나였다. 원장에게 보낼 양식·링크가 시스템에 없고, 보냈는지·받았는지도 어디에도 보이지 않았다.
파일에서 뽑은 글은 질문과 답이 섞여 필수 문구 선택이 `is_not_doctor_statement` 걸러내기에 기댔다.

## 결정(사용자, 2026-11-19)

- 양식은 마케팅팀 설문 미리보기(6부, 약 25문항)를 그대로 따른다. 미리보기의 검토 메모·미리보기 막대는 원장 화면에 싣지 않는다.
- 고쳐 쓰기: 제출 뒤에도 같은 링크로 고쳐 다시 제출한다. 다시 제출하면 같은 설문 자료를 **제자리에서** 바꾼다(옛 답이 근거로 남지 않게).
- 링크: 병원마다 살아 있는 링크 하나, 만료 없음. AE는 언제든 다시 복사하고, '새 링크 만들기'를 누르면 옛 링크가 막힌다.
- 임시 저장: 작성 중인 답은 서버에 저장한다. 근거 자료에는 제출한 답만 들어간다.
- 알림: 제출해도 Slack은 없다. 시스템이 원장에게 링크를 보내지 않는다. 상태는 병원 정보 탭 설문 카드에서 본다.
- 사실 답변(병원명·의료진·주소·전화·진료시간·채널 등)은 AE가 보고 반영한다(PR3). 측정 기준(검색 키워드·AI 질문·비교 병원)은
  지난달 비교를 깨므로 자동 반영하지 않는다.
- 동의 화면을 넣고, '15분 통화 미팅 요청' 버튼은 뺀다. 비급여 가격은 '제출일 기준'으로 안내한다.

### 근거 자료에 싣는 것

`essence`가 붙은 칸만 싣는다 — 진료 항목·설명, 늘리고 싶은 진료와 진료별 답(권유·과정·응급·당부), 자주 받는 질문의 답, 환자
동네·환자층·증상, 진료 환경, 한 줄 소개·특징, 개원 계기, 첫 진료 원칙·이유, 설명 방법, 말투, 쓰지 않을 표현.

- 줄 형식 `[원장 설문·종류] 라벨: 답`. 노트 발췌는 **답 부분만**이다(라벨이 필수 문구에 섞이지 않게).
- 필수 문구 후보(진료 철학·핵심 메시지 노트)는 '첫 진료 원칙'·'그 이유'·'한 줄 소개'뿐이다. 개원 계기는 긴 일화라 모든 글 끝에
  붙지 않게 지역·맥락 노트로 둔다. 보기로 문장을 지어 넣지 않는다.
- 긴 답은 문장 경계에서 380자 이하 여러 줄로 나눈다(합성 프롬프트의 설문 발췌 한도 400자).
- 가린 자리(`[가림]`)가 든 문장, 프롬프트 주입 의심·오류 페이지 잔재 줄은 뺀다(자료 전체가 빠지지 않게 줄만).
- 다시 제출하면 PROFILE_FACTS처럼 제자리에서 맞추고 그대로인 줄의 노트 id는 유지한다. 근거 철회(`invalidate_source_authority`)로
  다루지 않는다 — 공개 글을 숨기지 않는다.

### 개인정보

- 저장하는 모든 답(작성 중 답·제출한 답·근거 자료)에서 휴대전화·이메일·주민등록번호를 가린다(`survey_sources.mask_personal_info`).
  병원 대표 전화번호 칸과 숫자 칸은 그대로다.
- 공개 응답은 no-store·noindex·no-referrer, 설문 화면은 GA·픽셀 태그를 싣지 않는다(주소에 토큰).
- 답을 저장하기 전에 동의(판 `2026-11-19.1`)를 받는다. **동의 문구는 임시본이다** — 대표·법무 확정 전에는 실제 원장에게 링크를
  보내지 않는다.

## Essence에 주는 영향

- 제출(또는 다시 제출)하면 설문 자료 hash가 바뀌어 T3로 30분 디바운스 뒤 자동 판을 다시 만든다(제출 직후 태스크를 부르고, 실패하면
  15분 정기 조정이 집는다).
- **이미 운영 중인 병원**에 링크를 보내면: 옛 승인본(`synthesis_metadata` 없음)도 이 T3로 자동 판으로 넘어가고, 새 판의 필수 문구가
  원장의 설문 문장으로 바뀐다. 새 판 적용 뒤 병원의 글을 다시 판정하지만 공개 글은 판 교체로 숨지 않는다(E7).
- '병원 직원(대리 작성)'이 쓴 답도 원장 문장으로 쓰인다. 작성자는 `doctor_surveys.respondent`·감사 로그에 남는다.

## 알려진 한계·후속

- `LEAD_REPORT_TOKEN_SECRET`을 바꾸면 모든 설문 링크가 열리지 않는다(새 링크를 다시 만들어 보내야 한다).
- 올린 파일(PDF·DOCX)로 받은 설문의 `[가림]` 문장은 여전히 필수 문구가 될 수 있다(이 PR 밖, 엔진 규칙 후속).
- 무료 진단 상태 페이지(`/ai-diagnosis/status/{token}`)도 GA에 토큰 주소를 보낸다(이 PR 밖 후속).
- 문항 정의를 바꾸면 옛 답의 보기 값이 새 정의에 없어 저장이 거절될 수 있다 — 정의를 바꿀 때 `SCHEMA_VERSION`을 올리고 옛 답을
  옮기는 규칙을 함께 둔다.
