확인만 하고 고치지 않은 것:
- **오시는 길 '지하철' 문구**: 사이트 코드(`site/lib`·`site/app/[slug]`)의 기본 문구에는 '지하철'이 없다(11-17 #313 뒤). 공개 병원 15곳의 공개 응답에서 '지하철'은 병원이 직접 입력한 칸 두 곳뿐이다 — 마포성모탑 첫 화면 설명('지하철 5호선 마포역 2번 출구…'), 다대으뜸 대중교통 안내('부산 지하철 1호선 다대포항역…'). 둘 다 실제로 역이 있는 병원이다. 화면 확인은 행복드림·365서귀포·마포성모탑 홈과 오시는 길에서 했다. 코드 문제 아님 — 마케팅이 본 화면이 이 둘 중 하나인지 회의에서 확인.
- **행복드림 원장 「김」**: 연결된 사진이 '김효진 원장 캐릭터 일러스트'(`EDITORIAL_GRAPHIC`, 용도 `CONTENT_EDITORIAL`)라 공개 조건(실인물 인증 + 신원 사용 승인)을 못 넘는다 → 18번.
- **행복드림 공유 이미지(카카오·문자)**: `og:image`가 병원 사진이 아니라 플랫폼 기본 실내 사진(`/landing/reputation-clinic-trust-interior.png`)인데 대체 글은 '김효진 원장'이다 — 원장 사진이 공개 조건을 못 넘으면 플랫폼 사진으로 물러서면서 대체 글은 원장 이름을 그대로 쓴다(`page.tsx` `generateMetadata`). 대체 글이 사진과 다르다. 권장: 원장 사진이 없으면 병원 대표 사진(검증된 시설 사진)과 병원 이름을 쓴다(OG 메타만, JSON-LD는 그대로) — 공유 썸네일 직접 지정(편집기 `share`) 전에 고칠 작은 수정으로 따로 올릴지 결정.
- **B안 모바일 '평일은 / 08:30~18:30(…)'**: 입력 문장의 띄어쓰기에서 정상적으로 줄이 바뀐 것. 줄바꿈 지정(편집기 3.3)으로 푼다.
