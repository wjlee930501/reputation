**1단계 — 계약을 바꾸지 않는 수정(바로 시작)**

## 5. 두 세션 공통 규칙

- 매핑(조사 결과)은 위치 힌트일 뿐이다. 특히 어드민 쪽 조사는 옛 브랜치에서 일부 했다 → main에서 다시 확인.
- 마케팅이 11-20 운영 화면에서 본 것과 코드가 다르면(「이미 고쳐짐」·「의도된 계산」·「main에 지하철 문구 없음」) 운영 리비전과 실제 화면을 확인하기 전에는 「문제 아님」으로 닫지 않는다.
- **추적 측정 질문 문장은 건드리지 않는다** — 바꾸면 그 병원의 그 달 전체가 비교 불가다. FAQ 문장은 표시·브리프 쪽에서만 다듬는다.
- 공개 페이지의 구조화 정보(JSON-LD·llms.txt)는 화면 섹션 표시와 무관하게 같은 값이어야 한다. 단 **화면 FAQ와 FAQPage는 서로 같아야 한다**(같은 `selectFaqEntries` 배열).
- 문구: 어드민은 `ADMIN_COPY` + `scripts/check_user_facing_terms.py`, 공개 문구는 의료광고 필터.
- Codex CLI `gpt-6.1-sol` high 병렬 교차검토를 설계·diff·PR 직전마다. 받아들였는지 반박했는지 보고에 적는다.
- 디자인 변경은 시안·레퍼런스를 사용자와 먼저 맞춘다. 사용자에게 보이는 글은 한국어.
- PR 병합·배포는 사용자 결정. 배포는 `docs/ops/deployment-runbook.md`·`deploy.sh` 규칙.
