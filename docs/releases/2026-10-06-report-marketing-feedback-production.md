## 운영 데이터 수정

모든 변경은 Admin API(`X-Admin-Actor-System: marketing-feedback-2026-10`)로 했고 감사에
`system:marketing-feedback-2026-10`으로 남았다. 대상은 운영 DB 읽기 전용 조회(READ ONLY 트랜잭션,
`reputation-migrate` Job override)로 골랐다.

- **강심장내과 월간 추적 질문 2개**(월간 보고서에 쓰이는 `in_tracking_set` 중 문제는 이 둘뿐이었다):
  "마산 마산 심장초음파 진료 가능한 병원"은 추적 세트에서 빼고 같은 문장의 기존 질문 "마산 심장초음파 진료
  가능한 병원"을 넣었다(이름 변경은 고유 제약 409). "마산 마산 추천 진료 가능한 병원"은 이름·변형 2개를
  "마산 심장내과 진료 가능한 병원 추천"으로 바꿨다. 추적 세트는 15개 그대로다.
- **추적 세트 밖 질문 43건(5개 병원)**: 검사 키워드에 '치료' 문형이 붙은 33건은 이름·변형을 고쳤다
  ("…초음파 치료하려면 어떤 전문의한테 가야 해?" → "…초음파 검사는 어떤 전문의에게 받아야 해?",
  "치료 비용" → "검사 비용", "…초음파 치료하는 병원" → "…초음파 검사 받을 수 있는 병원").
  지역 중복·군더더기 10건("위례 위례 …", "마산 추천 …", "…에서 마산 심장초음파 …")은 보관(ARCHIVED)했다.
- **공개 글 제목 3편**: 연세속시원 "유방초음파 검사 비용, 검사 목적과 범위에 따라 달라지는 이유", 강심장내과
  "갑상선초음파 검사는 어떤 전문의에게 받아야 할까?"·"갑상선초음파 검사 비용보다 먼저 확인해야 할 것들".
  본문·설명문은 이미 '치료가 아니라 검사'라고 써 있어 고치지 않았다. 제목 변경이 지운 이미지 인증은
  `RECERTIFY_PUBLISHED_IMAGE` 실행 3건이 10초 안에 되살렸고, 환자 페이지에 새 제목·이미지로 보인다.
