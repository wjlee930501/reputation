# 노원탑365의원 시각 개선 제안

- 점검일: 2026-08-21
- 대상: `https://ai.no1top365.co.kr/`, `/doctor`, `/visit`
- 방법: Aside 브라우저로 데스크톱·390px 모바일 실사이트를 점검하고, 공식 홈페이지와 의료 서비스 레퍼런스를 비교했다.
- 범위: 디자인·정보 구조 제안. 프로덕션 코드는 변경하지 않았다.

## 현재 화면

### 1. 홈 — 데스크톱

![홈 데스크톱](01-home-desktop-viewport.png)

**상태: 전반적으로 양호, 브랜드 일치도는 낮음.** 원장 실사진, 명확한 제목, 전화·방문 CTA가 신뢰 형성에 효과적이다. 다만 현재 로열 블루와 네이비는 노원탑의 공식 청록 계열 브랜드와 연결되지 않는다. 콘텐츠가 1편뿐인데 여러 모듈에서 반복돼 하단이 템플릿처럼 느껴진다.

### 2. 홈 — 모바일

![홈 모바일](02-home-mobile-accepted.png)

**상태: 양호, 첫 화면 밀도 조정 필요.** 390px에서 가로 넘침은 없고 CTA도 명확하다. 그러나 긴 제목이 다섯 줄을 차지해 ‘오늘 진료 여부·시간’ 같은 즉시 판단 정보가 늦게 보인다.

### 3. 의료진 — 모바일

![의료진 모바일](03-doctor-mobile-accepted.png)

**상태: 개선 필요.** 페이지 도입부와 의료진 섹션 도입부가 중복되고 ‘대표원장’도 반복된다. 사진과 핵심 경력 사이의 거리가 길어 첫 화면의 정보 효율이 낮다.

### 4. 진료 안내 — 모바일

![진료 안내 모바일](04-visit-mobile-accepted.png)

**상태: 개선 필요.** ‘진료 안내’와 ‘오시는 길·방문 안내’의 의미가 중복된다. 방문 목적 페이지인 만큼 오늘 진료시간, 전화, 길찾기를 설명문보다 먼저 보여주는 편이 낫다.

## 공식 브랜드에서 가져올 것

![노원탑 공식 홈페이지](05-official-desktop-viewport.png)

공식 홈페이지에서는 **로고와 색상 자산만** 가져오고, 오래된 밀집 레이아웃이나 우측 플로팅 메뉴는 가져오지 않는다.

| 역할 | 색상 | 사용 규칙 |
|---|---:|---|
| Primary / CTA | `#006772` | 버튼, 핵심 링크, 로고 기반 강조. 흰색 텍스트 사용 가능(대비 6.6:1). |
| Support | `#0089A0` | 큰 장식 면·아이콘. 일반 크기 흰색 텍스트는 피한다. |
| Fresh accent | `#35B998` | 상태·선·작은 강조. 흰색 텍스트 금지, 짙은 잉크와 조합한다. |
| Ink | `#102A33` | 본문과 mint 배경 위 텍스트. |
| Brand wash | `#EAF7F4` | 얕은 섹션 배경. |
| Paper | `#FBFCFA` | 기본 배경. |
| Line | `#D7E7E3` | 구분선과 입력 테두리. |

권장 비율은 중립색 80%, 짙은 브랜드색 15%, 밝은 포인트 5%다. 이 비율이면 ‘병원마다 색을 칠한 템플릿’이 아니라 차분한 의료 브랜드로 보인다.

## 제안하는 디자인 시스템

### 1. 자유 색상 선택이 아닌 제한적 시맨틱 테마

이미 Admin과 API에는 `brand_primary_color`, `brand_accent_color`, `logo_url`이 존재한다. 그러나 공개 홈은 테마 스타일을 적용하지 않고, CSS도 `--clinic-primary`와 `--clinic-accent` 변수를 소비하지 않아 설정이 실질적으로 끊겨 있다.

새 컬러 피커를 더 만들기보다 다음 토큰으로 연결한다.

- `brand-strong`, `brand`, `brand-fresh`, `on-brand`
- `brand-soft`, `ink`, `paper`, `line`, `focus`

AE는 공식 로고와 대표색 한 개를 확인하고, 시스템이 접근성 안전한 톤을 파생한다. Admin에는 홈 헤더·CTA·모바일 첫 화면 미리보기와 대비 경고를 제공한다. 밝은 색을 본문이나 CTA 배경에 잘못 쓰는 상황은 저장 단계에서 막는다.

### 2. 병원별 완전 커스텀 대신 세 가지 검증된 아키타입

- **Availability-first**: 365일·야간·당일진료형. 노원탑에 적용. 오늘 진료시간, 전화, 길찾기를 첫 화면에 둔다.
- **Doctor-first**: 단일 전문의·경력 신뢰가 핵심인 의원. 원장 사진과 검증 가능한 경력을 먼저 둔다.
- **Content-first**: 질환·치료 콘텐츠가 충분한 병원. 대표 글 한 편과 보조 글을 편집형으로 구성한다.

공통 컴포넌트와 정보 구조는 유지하고 첫 화면의 우선순위와 대표 섹션만 바꾼다. 병원마다 전혀 다른 사이트를 만드는 비용과 품질 편차를 피할 수 있다.

### 3. 노원탑에 바로 적용할 정보 구조

1. 헤더에 공식 로고를 사용한다.
2. 히어로 제목을 줄이고 `오늘 09:00–21:00 · 주말/공휴일 진료`처럼 사실 기반 운영 정보를 제목 바로 아래 둔다.
3. 의료진 페이지는 두 개의 도입부와 반복되는 ‘대표원장’을 하나로 합치고, 사진 옆/직후에 핵심 경력을 배치한다.
4. 진료 안내 페이지는 오늘 시간 → 전화 → 길찾기 → 전체 시간표 순으로 재배치한다.
5. 사진 22장을 모두 전시하지 말고 외관·접수·진료실·장비 중심 6–8장을 큐레이션한 뒤 ‘더 보기’로 확장한다.
6. 게시 글이 적을 때는 같은 글을 여러 영역에 반복하지 않고, 한 편을 크게 보여준다. 충분히 쌓이면 대표 글 1개 + 보조 글 2–4개 구조로 전환한다.

## 레퍼런스에서 가져올 원칙

### One Medical

![One Medical](06-reference-one-medical.png)

한 장의 강한 사진, 짧은 주장, 넉넉한 여백을 참고한다. 서체나 미국식 라이프스타일 톤을 그대로 복제하지 않는다.

### HSS

![HSS](07-reference-hss.png)

사용자 과업을 첫 화면에서 바로 시작시키는 구조를 참고한다. 노원탑에서는 ‘의사 찾기’ 대신 오늘 시간·전화·길찾기가 된다. 순위나 수상 표현은 근거 없이 차용하지 않는다.

### Cleveland Clinic Health Essentials

![Cleveland Clinic Health Essentials](08-reference-cleveland-health.png)

모든 콘텐츠를 같은 카드로 늘어놓지 않고 대표 글과 보조 글의 위계를 나누는 편집 구조를 참고한다.

## 슬롭 방지 규칙

- 그라디언트, 글래스모피즘, 노이즈 텍스처, 과도한 그림자와 둥근 카드 군집을 쓰지 않는다.
- 배지·필·플로팅 요소를 상태마다 반복하지 않는다.
- 가짜 수상, 순위, ‘최고’ 표현과 스톡 환자 이미지를 쓰지 않는다.
- Pretendard를 유지하고 차별화는 공식 브랜드, 실사진, 정보 위계에서 만든다.
- 뷰포트마다 기본 행동은 하나만 강하게 둔다. 보조 행동은 텍스트 또는 아웃라인으로 낮춘다.
- 터치 타깃 44px 이상, 본문 대비 WCAG AA, 390px 가로 넘침 없음, 모션은 hover·focus·press 150–200ms만 허용한다.

## 우선순위

1. **P0:** 끊긴 테마 토큰 연결, 공식 로고·팔레트 입력, 대비 자동 검증과 미리보기.
2. **P1:** 노원탑을 Availability-first로 재구성하고 의료진·진료 안내 중복을 제거한다.
3. **P2:** 온보딩 시 공식 사이트/로고에서 팔레트를 자동 제안하되 AE 승인 후 적용하고, 세 아키타입 중 하나를 선택한다.

## 검증 한계

이번 점검은 실제 공개 화면의 Aside 캡처, DOM 구조, 390px 가로 넘침, 색상 대비를 확인했다. 키보드 전수 탐색, 스크린리더 읽기 순서, 다양한 실제 기기와 네트워크 조건까지 포함한 WCAG 전체 감사는 아니다.
